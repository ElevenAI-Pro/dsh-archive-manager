# Eleven_AI 提示词工具集

> 为 `dsh-archive-management` 项目（Eleven_AI 出品）定制的一套专业提示词。
> 使用方法：复制任意一条完整提示词到 AI 对话框（DeepSeek / Claude / GPT 均可），
> 把【】标记的变量替换成实际内容即可。建议按 P1→P8 的顺序收藏。

| 编号 | 场景 | 使用频率 |
|---|---|---|
| P1 | 版本发布（发布说明 + 公告 + 推文一次生成） | 每次发版 |
| P2 | 用户 Issue 分类与专业回复 | 每条 issue |
| P3 | 自媒体短视频脚本（60 秒带钩子） | 每条视频 |
| P4 | 图文帖 / 公众号长文案 | 每篇图文 |
| P5 | 深度代码审查（按本插件技术栈定制） | 每次改代码 |

| P7 | README / 文档优化 | 大改后 |

## 使用心法（Eleven_AI 专属）

1. **先给上下文再提问**：P2/P5/P8 这类提示词，把真实材料粘贴进【】位置，AI 的输出质量翻倍
2. **把输出当草稿不当结论**：AI 写的回复/文案，用你自己的语气过一遍再发——你的人设是 Eleven_AI，不是 AI
3. **固定一套、微调迭代**：找到一条用得顺的提示词后，把你的修改沉淀回这个文件，形成你自己的版本
4. **提示词本身也开源**：这套工具集就在仓库里 `docs/PROMPTS.md`，用户看到会觉得这个作者连提示词都工程化——本身就是曝光点
