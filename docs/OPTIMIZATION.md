# 深度优化分析（OPTIMIZATION）

> 审查日期：2026-11-20 · 审查人：Eleven_AI 维护者视角（对照上游 xohmai v0.5.1 与 jasonrale 同名竞品）
> 结论先行：核心链路（永久删除/级联/审计/CSRF/测试）已达开源及格线以上；下面这些是「做到极致」要补的。

## P0 正确性与一致性（本次发布 1.2.1 全部修复 ✅）

| # | 问题 | 场景后果 | 修复 |
|---|---|---|---|
| P0-1 | **软删除不级联**：删父会话进回收站，子代理会话留在原位 | 子代理日志永久变孤儿，占磁盘且侧栏残留 | deleteSession 级联：全部后代逐一入回收站（各自可独立还原），任一子代理运行中则整体 409 |
| P0-2 | **purge-archived 不级联**：永久清空已归档会话时，未归档的子代理残留 | 「全部永久删除」删不干净 | 目标集合扩展为「已归档 ∪ 其全部后代」，运行中跳过并计数 |
| P0-3 | **saveConfig 非原子写**：写 config.json 中途崩溃 → 配置损坏，自动归档失效 | 低概率但后果是静默失效 | 临时文件 + rename 原子替换（与回收站 meta.json 同标准） |
| P0-4 | **/debug GET 无鉴权**：遥测含菜单结构快照（可能含会话标题），本机任意程序可读 | 信息泄露面（低危但不一致） | GET 也要求 `x-dsh-plugin` 头，与其他路由统一 |

## P1 重要（下版本）

| # | 事项 | 说明 |
|---|---|---|
| P1-1 | 大列表虚拟化 | 数百会话时 DOM 行数过高；列表区改虚拟滚动或「每页 100 条」 |
| P1-2 | 设置页英文 i18n | npm 面向全球，界面文案目前仅中文；菜单半已有 en 字典，设置页补齐 |
| P1-3 | 还原父会话时级联还原子代理 | 回收站按条独立还原：还原父后应提示/一键还原其 trash 中的子代理 |
| P1-4 | 回收站过期自动清理 | 给回收站加保留期（如 30 天），到期自动彻底删除（审计留痕） |
| P1-5 | 自动归档结果 Toast | 后台扫描归档了会话时，前台应弹通知告知（现在静默） |
